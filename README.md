# CTBU 电费查询与自动推送插件

一个用于查询重庆工商大学各校区电费余额并支持自动推送的 AstrBot 插件。

## 功能特性

- **多校区支持**：支持茶园校区、兰花湖校区、南岸校区（北区、南区、研究生公寓）
- **任意房间查询**：支持查询任意房间的电费余额
- **灵活推送设置**：支持定时推送和低余额推送，可独立开关
  - 定时推送：可自定义每日推送时间（默认10点）
  - 低余额推送：余额低于阈值时自动提醒
- **房间绑定记忆**：绑定后查询电费无需再输入房间号，自动使用绑定的房间
- **个性化阈值**：每个用户可设置自己的低余额提醒阈值（默认 10 元）
- **智能提醒**：余额低于阈值时自动显示缴费入口链接
- **数据持久化**：使用 KV 存储保存配置信息，重启后不会丢失
- **快捷缴费**：一键获取电费缴费入口

## 快速开始

### 首次使用流程

1. **绑定房间**
   ```
   /订阅电费 cy10-101
   ```
   绑定成功后，房间信息会自动保存

2. **开启定时推送**（可选）
   ```
   /开启推送
   ```
   启用后每天会在指定时间自动推送电费信息

3. **开启低余额推送**（可选）
   ```
   /开启低余额推送
   ```
   启用后余额低于阈值时自动推送提醒

4. **设置推送时间**（可选，默认10点）
   ```
   /设置推送时间 8
   ```
   默认为10点，可根据需要调整

5. **查询电费**
   ```
   /电费
   ```
   绑定后无需再输入房间号

### 推送管理

插件提供两种独立的推送功能，可以根据需要选择开启：

#### 1. 定时推送

在每天固定时间推送电费信息。

**开启/关闭**
```
/开启推送       # 开启定时推送
/关闭推送       # 关闭定时推送
```

**设置推送时间**
```
/设置推送时间 <小时>
/推送时间 <小时>
/set_push_time <小时>
```

示例：
```
/设置推送时间 8      # 设置为每天8点推送
/设置推送时间 10     # 设置为每天10点推送（默认）
/设置推送时间 18     # 设置为每天18点推送
/设置推送时间        # 查看当前推送时间
```

**说明**：
- 默认推送时间为每天10点
- 小时范围：0-23
- 每个用户可以设置不同的推送时间
- 修改时间不影响推送开关状态

#### 2. 低余额推送

当电费余额低于设定阈值时自动推送提醒。

**开启/关闭**
```
/开启低余额推送       # 开启低余额自动提醒
/关闭低余额推送       # 关闭低余额自动提醒
```

**说明**：
- 每小时检查一次电费余额
- 余额低于阈值时立即推送提醒
- 每天最多提醒一次，避免骚扰
- 余额恢复阈值以上后重置提醒状态
- 可与定时推送同时开启，互不影响

**使用场景**：
- 只想在余额不足时收到提醒：只开启低余额推送
- 想每天定时了解余额情况：只开启定时推送
- 既想定时了解又想余额不足提醒：两个都开启

```

示例：
```
/设置轮询间隔 0     # 默认：每小时整点检查
/设置轮询间隔 30    # 每30分钟检查一次
/设置轮询间隔 60    # 每60分钟检查一次
/设置轮询间隔       # 查看当前设置

**说明**：

- 所有时间均基于东八区（UTC+8）

## 注意事项

1. **数据持久化**：所有配置（房间绑定、阈值、推送设置）使用 KV 存储保存，插件重启后不会丢失
2. **房间号格式**：房间号格式必须包含校区前缀，如 `cy10-101`
3. **网络要求**：请确保网络能正常访问校园网电费查询接口
4. **时区**：所有时间均基于东八区（UTC+8，北京时间）
5. **阈值设置**：默认低余额阈值为 10 元，可通过 `/设置阈值` 命令自定义
6. **推送设置**：
   - 默认推送时间为每天 10:00（东八区）
   - 默认推送状态为关闭，需手动开启
   - 定时推送和低余额推送可独立开关
   - 每个用户可设置不同的推送时间和阈值
7. **轮询间隔**：
   - 默认每小时整点检查一次（0:00, 1:00, ..., 23:00 CST）
   - 可通过 `/设置轮询间隔` 自定义，最小 5 分钟
   - 全局设置，对所有订阅用户生效
8. **低余额推送**：
   - 每次轮询时检查，低于阈值立即提醒
   - 每天最多提醒一次
   - 余额恢复后重置提醒状态
9. **缴费提醒**：余额低于设定阈值时会自动显示缴费入口链接
